# RelUX by KAI — Alert & Banner
> Pesan banner kontekstual untuk pemberitahuan status dan notifikasi error.

- **Kategori:** Feedback
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::alert>`)
  - React: `@kai/relux-react` (`<Alert & Banner />`)
  - Angular: `@kai/relux-angular` (`relux-alert`)
  - CSS: `@kai/relux-css` (`.relux-alert`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
