# RelUX by KAI — Form Controls
> Elemen input form aksesibel: text, password show/hide, select, textarea, checkbox, radio, switch.

- **Kategori:** Form
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::form>`)
  - React: `@kai/relux-react` (`<Form Controls />`)
  - Angular: `@kai/relux-angular` (`relux-form`)
  - CSS: `@kai/relux-css` (`.relux-form`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
