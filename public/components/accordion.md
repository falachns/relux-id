# RelUX by KAI — Accordion
> Komponen lipat/buka konten dengan animasi dan aksesibilitas ARIA.

- **Kategori:** Disclosure
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::accordion>`)
  - React: `@kai/relux-react` (`<Accordion />`)
  - Angular: `@kai/relux-angular` (`relux-accordion`)
  - CSS: `@kai/relux-css` (`.relux-accordion`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
