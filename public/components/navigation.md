# RelUX by KAI — Navigation
> Pola navigasi antar halaman dan panel: breadcrumbs, tabs, dan pagination.

- **Kategori:** Navigation
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::navigation>`)
  - React: `@kai/relux-react` (`<Navigation />`)
  - Angular: `@kai/relux-angular` (`relux-navigation`)
  - CSS: `@kai/relux-css` (`.relux-navigation`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
