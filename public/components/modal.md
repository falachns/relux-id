# RelUX by KAI — Modal & Dialog
> Dialog modal berbasis native HTML5 dialog dengan focus trap dan escape handler.

- **Kategori:** Overlays
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::modal>`)
  - React: `@kai/relux-react` (`<Modal & Dialog />`)
  - Angular: `@kai/relux-angular` (`relux-modal`)
  - CSS: `@kai/relux-css` (`.relux-modal`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
