# RelUX by KAI — Progress & Loaders
> Progress bar linear, spinner berputar, dan skeleton shimmer placeholder.

- **Kategori:** Feedback
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::progress>`)
  - React: `@kai/relux-react` (`<Progress & Loaders />`)
  - Angular: `@kai/relux-angular` (`relux-progress`)
  - CSS: `@kai/relux-css` (`.relux-progress`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
