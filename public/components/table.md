# RelUX by KAI — Data Table
> Tabel data terstruktur dengan pencarian, sorting, status badges, dan paginasi.

- **Kategori:** Data Display
- **Status:** Stable (Make Kit KAI v1)
- **Paket Resmi:**
  - Blade: `kai/relux-ui` (`<x-relux::table>`)
  - React: `@kai/relux-react` (`<Data Table />`)
  - Angular: `@kai/relux-angular` (`relux-table`)
  - CSS: `@kai/relux-css` (`.relux-table`)

## Standar Penggunaan
- Selalu gunakan token semantik Make Kit KAI (`--colors/kai/...`, `--radius-...`, `--spacing-...`).
- Hindari inline style dan arbitrary classes.
- Pertahankan touch target minimal 44x44px pada layar mobile.
- Pastikan interaksi keyboard (Tab, Enter, Space, Escape, Arrow keys) berfungsi penuh.
